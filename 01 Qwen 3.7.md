**Анализ стеков:**
*   **Rust/Tauri:** Рекомендуемый выбор. HTML/CSS/JS идеально подходят для рендеринга reflowable-текста (EPUB). Малый размер бинарника, высокая производительность, отличная кроссплатформенность.
*   **Python/PyQt:** Быстрый старт, но рендеринг сложной верстки EPUB требует QtWebEngine, что критически увеличивает размер приложения и потребление памяти.

**Информация по движкам рендеринга:**
Писать парсер и рендерер с нуля нецелесообразно.
*   **Для Tauri:** Использование WebKit/Chromium (встроенных в Tauri) с библиотеками вроде Epub.js. FB2 придется конвертировать в HTML на бэкенде (Rust).
*   **Для PyQt:** QtWebEngine для отображения HTML-контента. 
*   **MuPDF:** Мощная C-библиотека. Отлично рендерит EPUB/PDF, но требует написания UI с нуля и сложна в интеграции. Не рекомендуется для MVP.

**Обновленный план реализации:**
1.  **Архитектура данных:** SQLite для хранения метаданных, обложек, закладок и прогресса. Файловая система (с индексацией) для самих книг.
2.  **Бэкенд (Rust/Python):** Разработка парсеров. Извлечение метаданных, генерация обложек, конвертация FB2 в HTML (если выбран Tauri).
3.  **UI библиотеки:** Реализация гибридного вида: навигация по папкам + сетка/список книг с метаданными из БД.
4.  **Движок чтения:** Интеграция веб-рендерера. Реализация пагинации, парсинга оглавления (TOC), сохранения позиций (CFI для EPUB, байт-оффсет для TXT).
5.  **Сборка:** Настройка кросс-компиляции с приоритетом на Windows (MSVC/NSIS).

## Финальный план реализации на базе Rust/Tauri.

### Этап 1. Инициализация и архитектура
- Настройка проекта Tauri (Rust + легковесный фронтенд, например, Svelte или SolidJS).
- Проектирование схемы SQLite: таблицы books (метаданные, путь к файлу), progress (позиция чтения), bookmarks (закладки).
- Настройка IPC (Tauri Commands) для связи фронтенда и бэкенда.

### Этап 2. Бэкенд (Rust) и парсинг
- Реализация чтения файловой системы (сканирование директорий, генерация и кэширование обложек).
- Интеграция крейтов: `epub` (для EPUB), `quick-xml` (для парсинга FB2 и конвертации в HTML), стандартные библиотеки для TXT.
- Настройка работы с SQLite (через `sqlx` или `rusqlite`).

### Этап 3. Фронтенд (UI)
- Экран библиотеки: гибридный вывод (дерево папок + сетка книг с обложками из БД).
- Экран чтения: рендеринг HTML-контента через встроенный WebView. Настройка шрифтов, межстрочного интервала, тем.
- Боковая панель: интерактивное оглавление (TOC) и список закладок.

### Этап 4. Логика чтения и сохранения
- Реализация пагинации (постраничное отображение контента в WebView).
- Трекинг прогресса: CFI (Canonical Fragment Identifier) для EPUB, смещение байтов/строк для TXT и FB2.
- Автосохранение позиции и закладок в SQLite через IPC.

### Этап 5. Сборка и дистрибуция
- Настройка CI/CD для кросс-компиляции.
- Сборка инсталлятора для Windows (NSIS или WiX).
- Тестирование производительности, оптимизация потребления памяти WebView.
