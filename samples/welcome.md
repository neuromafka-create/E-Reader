# Welcome to E-Reader

This is a **Markdown** sample book used to verify the first reading pipeline.

## What works now

- Library folders and file import
- SQLite storage for books, progress, and bookmarks
- Reading for **TXT** and **Markdown**
- Table of contents from Markdown headings
- Themes, font size, progress auto-save

## What comes next

1. EPUB via WebView + epub tooling
2. FB2 → HTML conversion on the Rust side
3. Cover extraction and richer metadata
4. Optional cloud sync later

### Nested section

Markdown headings become an interactive TOC in the sidebar.

> Tip: press **Bookmark** while reading to save your place.
