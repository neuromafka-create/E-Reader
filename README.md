# E-Reader

> 🇬🇧 [English README](./README.en.md)

Десктопная читалка электронных книг (приоритет — **Windows**, кроссплатформенность заложена) на стеке **Rust + Tauri 2 + SvelteKit**.

| Формат | В библиотеке | Чтение | Метаданные / обложки |
|--------|--------------|--------|----------------------|
| TXT | да | да | название из имени файла |
| Markdown (`.md`, `.markdown`) | да | да + оглавление | заголовок H1 |
| EPUB | да | да + оглавление + картинки | title, author, cover |
| FB2 | да | да + оглавление + картинки | title, author, cover |

## Возможности

- Интерфейс на **русском** и **английском** (выбор языка в библиотеке и в читалке)
- **Сквозные** тема и язык: меняете на главной — применяются в книге и наоборот; оба сохраняются
- Гибридная библиотека: папки и/или импорт отдельных файлов
- SQLite: книги, прогресс чтения, закладки, настройки
- Темы (сепия / светлая / тёмная)
- **Типографика в читалке**: выбор семейства шрифта (Georgia, Times, Arial, Segoe UI и др.) и размер числом (12–40 px), настройки сохраняются
- **Устойчивые позиции чтения**: доля документа + ближайший якорь секции  
  (лучше переживают смену шрифта, чем «сырые» пиксели; старый формат `scroll:px` тоже открывается)
- Подсветка текущего пункта оглавления при прокрутке
- Клавиатура: `←`/`→` или `PageUp`/`PageDown` — «страница», `Esc` — в библиотеку; закладка — **выделить текст** и `B`
- Извлечение обложек для EPUB/FB2 (в сетке библиотеки)
- Установщики Windows (NSIS + MSI)
- «Открыть с помощью» / CLI: запуск с путём к книге → импорт и открытие
- Drag-and-drop книг или папок в окно приложения
- Ссылки в книге: внешние страницы — в системном браузере; прямые/скачиваемые книги — в библиотеку (без «чёрного экрана»)

## Требования

- [Rust](https://www.rust-lang.org/) (stable)
- [Node.js](https://nodejs.org/) 20+
- Windows: MSVC Build Tools (для Tauri)

## Запуск

```bash
npm install
npm run tauri:dev
```

Примеры книг лежат в `samples/`:

- `plain.txt`, `welcome.md`
- `example.epub` (тестовый EPUB)
- `sample.fb2`

Используйте **Import files** или **Add folder** и укажите каталог `samples`.

## Сборка (установщик Windows)

```bash
npm run tauri:build
```

Артефакты появятся в `src-tauri/target/release/bundle/`:

- `nsis/*.exe` — установщик для текущего пользователя
- `msi/*.msi` — MSI-пакет

## «Открыть с помощью» и drag-and-drop

- **Двойной клик / «Открыть с помощью»** (после установки с ассоциациями файлов): приложение импортирует файл и открывает его.
- **CLI**: передайте пути после бинарника, например  
  `E-Reader.exe samples\welcome.md`
- **Drag-and-drop**: перетащите в окно файлы `.epub` / `.fb2` / `.md` / `.txt` или папку.
  - Файлы добавляются в библиотеку; папки становятся корнями библиотеки и сканируются.
  - Если импортирован хотя бы один файл, первый из них открывается в режиме чтения.

## Клавиши (режим чтения)

| Клавиша | Действие |
|---------|----------|
| `←` / `PageUp` | Предыдущий «экран» |
| `→` / `Space` / `PageDown` | Следующий «экран» |
| `Home` / `End` | Начало / конец книги |
| `B` | Добавить закладку |
| `Esc` | Вернуться в библиотеку |

## Архитектура

```
src/                      UI на SvelteKit (библиотека + читалка)
src-tauri/src/
  commands.rs             IPC-команды Tauri
  db.rs                   SQLite
  download.rs             Скачивание книг по URL из ссылок
  formats/
    txt.rs                TXT → HTML
    markdown.rs           Markdown → HTML + оглавление
    epub.rs               EPUB через rbook (главы, картинки как data URI)
    fb2.rs                FB2 → HTML через крейт fb2
  models.rs               DTO
```

Данные приложения (`library.db`, `covers/`) хранятся в каталоге app data ОС для идентификатора `com.mafka.ereader`.
